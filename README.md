# TechPulse

AI-powered opportunity discovery and recommendation platform for students.

## Vision
Help students discover relevant hackathons, internships, fresher jobs, technical fests, and workshops.

## Planned Tech Stack
- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL
- AI/ML: scikit-learn and NLP, only where useful

## Development Status
Project setup in progress. Features will be added and tested incrementally.

## Principles
- Build useful features, not unnecessary AI.
- Use verifiable opportunity sources.
- Keep the application secure, maintainable, and accessible.
